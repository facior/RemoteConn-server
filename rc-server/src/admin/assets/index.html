Serwer zna tylko klucze publiczne kont, nigdy hasła. Zablokowanie konta albo odebranie dostępu urządzeniu działa od razu na komputerach konta, które są online. Resetu hasła nie ma: konto trzeba usunąć i założyć ponownie.

Relay przekazuje tylko zaszyfrowane dane (Noise end-to-end). Panel widzi adresy i liczbę bajtów, nigdy treść.
